# M1 — Core foundation

M1 starts the executable AmiChat core.

## Implemented

- Context lifecycle
- Provider and model selection state
- Conversation allocation
- Stable public result codes
- Error reporting
- Host-side C test harness
- Portable C89-oriented implementation
- Make-based host build

## Intentionally not implemented yet

- Real provider HTTP calls
- Streaming transport
- Conversation persistence
- Native Amiga GUI
- ARexx runtime
- Export encoders
- Printing

The next increment should add the transport/provider abstraction and the generic OpenAI-compatible adapter, backed by AmiAPI on Amiga.

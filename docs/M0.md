# M0

M0 establishes the project identity, MIT license, provider-neutral architecture, core and provider interfaces, AmiAPI integration boundary, native non-MUI GUI direction, ARexx architecture, export and printing architecture, security boundaries, and host-side testing direction.

M0 does not claim working provider integrations, GUI widgets, ARexx runtime, export encoders, printer backend, credential manager or persistence backend.

M1 candidates: core conversation implementation, generic OpenAI-compatible provider, AmiAPI-backed HTTP adapter, basic CLI/test harness, first native Amiga window, initial ARexx port and native conversation storage.
